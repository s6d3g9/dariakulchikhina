# packages/card-types/course

Курс — classic creator economy example. Instance = «я прохожу курс». Type = «курс как продукт».

## Instance (моё прохождение)

- TIMELINE: enrolled → modules (N steps) → graduation.
- Left: purchase-info, certificate, downloads.
- Right: teacher chat, cohort community (если есть).
- Top: my learning captures (screenshots, notes I shared).
- Bottom: my learning journal.

## Type (курс как продукт)

- Marketplace mode.
- Left: purchase / subscribe CTA, related courses, course materials overview, teacher's other offerings.
- Right: course community (alumni), teacher follows.
- Top: promo content, student work showcase.
- Bottom: reviews + updates (new modules, fixes).
- Lineage: если форк другого course template — visible.

## Primitives

`authorship-registry` (teacher is author), `subscription-engine` или `payments` (one-time), `timeline-engine` (learning progress), `pattern-engine` (course structure as template), `reviews-ratings`, `media-pipeline` (videos), `feed` (teacher updates), `messenger` (cohort / teacher).

## Fork opportunity

Teacher publishes course as `pattern-template`. Другой teacher может fork и adapt (с royalty).
