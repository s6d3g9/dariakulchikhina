# Incidents (Post-mortems)

Post-mortems каждого SEV-1 и SEV-2 incident'а. Blameless. См. `51-incident-response.md §8`.

## Format

`YYYY-MM-DD-<slug>.md`. См. [TEMPLATE.md](TEMPLATE.md).

## Cross-references

- Runbooks: `docs/runbooks/` — alerts that fired.
- ADRs: если выводы post-mortem приводят к архитектурному решению → ADR.
- RFCs: если выводы требуют нового processing — RFC.
