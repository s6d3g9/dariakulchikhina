# Playbooks

Golden-path руководства для типовых задач инжиниринга v6. Отличаются от runbook'ов (которые — для incidents).

| Playbook | Для кого | Частота |
|---|---|---|
| [add-card-type.md](add-card-type.md) | Developer adding a new vertical | 1-5 / month |
| [deploy-new-service.md](deploy-new-service.md) | DevOps / Platform | 1-2 / month |
| [rotate-jwt-key.md](rotate-jwt-key.md) | Security | 2 / year |
| [handle-gdpr-erase.md](handle-gdpr-erase.md) | Security / compliance | on-demand |
| [investigate-slow-query.md](investigate-slow-query.md) | Developer / DBA | on-demand |
| [rollback-bad-migration.md](rollback-bad-migration.md) | Platform / DB ops | rare |
| [onboard-new-vertical.md](onboard-new-vertical.md) | Platform + squad | new phase |

Добавляйте новые когда типовая задача повторяется ≥ 3 раза.
